# Encuadre del framework utilizado

## Framework seleccionado
El proyecto Noir Atelier utiliza **Next.js** con **App Router** y se desarrolla con **React.js** en **JavaScript**.

## Por qué se eligió Next.js
- Permite estructurar rutas como carpetas de manera clara.
- Facilita la creación de páginas estáticas y dinámicas.
- Soporta componentes reutilizables.
- Ofrece una configuración moderna con CSS global.

## Ventajas para el proyecto
- Estructura ordenada y escalable.
- Renderizado rápido y primera carga optimizada.
- Ideal para un blog editorial con diseño minimalista.
- Permite demostrar manipulación directa del DOM en un componente cliente.
