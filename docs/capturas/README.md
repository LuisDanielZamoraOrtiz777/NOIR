# Carpeta de capturas

Aquí puedes almacenar las capturas de pantalla que sirvan como evidencia del proyecto.

Recomendaciones:
- Usa nombres claros como `inicio.png`, `dom-antes.png`, `dom-despues.png`.
- Guarda las capturas directamente en esta carpeta.
- Añade anotaciones si es necesario para señalar los elementos clave.
